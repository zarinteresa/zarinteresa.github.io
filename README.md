# zarinteresa.github.io

Personal portfolio — plain HTML/CSS/JS, no build step.

- `index.html` – all content (Home and Courses views, hash-routed)
- `assets/css/style.css` – styles, light/dark themes via CSS variables
- `assets/js/main.js` – theme toggle, routing, avatar hover effect
- `.nojekyll` – serve files as-is on GitHub Pages

Preview locally: `python3 -m http.server` then open http://localhost:8000
